Apri [il faucet ufficiale Solana](https://faucet.solana.com). Con GitHub il limite può aumentare. In alternativa [DevnetFaucet.org](https://devnetfaucet.org) richiede l'accesso GitHub e indica fino a 20 SOL di test. Completa personalmente eventuali verifiche o autorizzazioni richieste dal faucet.

Circa **10 SOL di test** sono un margine iniziale per programma, circuiti, account Arcium e partite. Anche un importo piccolo può permettere di avviare il faucet proof-of-work ufficialmente documentato. Il faucet pubblico via CLI ha rifiutato le richieste automatiche per i limiti di utilizzo.

**Non acquistare SOL e non trasferire SOL reali.** Non serve una seed phrase o il wallet personale: è già stato creato un wallet dedicato, le cui chiavi sono ignorate da Git e dall'upload Vercel.
